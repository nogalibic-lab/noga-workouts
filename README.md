# Noga Workouts

אפליקציית אימונים סלולרית בעברית. ה־frontend מתארח ב־GitHub Pages והנתונים נשמרים ב־Supabase.

## פרטיות
המאגר ציבורי ולכן אין לשמור בו נתוני אימונים, מפתחות Supabase סודיים או קישורי גישה אישיים. האפליקציה משתמשת בקישור אישי; השרת שומר רק hash של מפתח הגישה.

## מבנה
- `index.html` — מסך האפליקציה
- `styles.css` — עיצוב RTL ומובייל
- `app.js` — ממשק ותקשורת עם API
- Supabase Edge Function `workout-api` — אימות, קריאה ושמירה

נתוני התוכנית והאימונים אינם נמצאים במאגר GitHub.
