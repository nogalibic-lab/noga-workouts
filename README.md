# Noga Workouts

אפליקציית אימונים סלולרית בעברית. הממשק מתארח ב־GitHub Pages והנתונים נשמרים ב־Supabase.

## התוכנית הנוכחית

`program.js` מגדיר את התוכנית הכללית שאושרה: רצף A → B → C שאינו מתאפס בתחילת שבוע, ואימון D אופציונלי שאינו מקדם את הרצף. נפח הבסיס הוא 16/18/18/12 סטים, לפני קפיצות ותוספות. שתי הצעות קבועות ועד שתי בחירות מתפריט; בחירה חוזרת מוסיפה סטים באותו כרטיס. התוכנית החדשה היא `general_v3`; כל התוכניות והאימונים הקודמים נשמרים.

מסך האירובי נפרד. מנגנון האירובי הקיים וחישוב הדקות אינם משתנים. כל המלצות ההתקדמות ומידע ההתאמה נפתחים לפי בקשה.

## מבנה ומידע

- `program.js`: מרשם התוכנית, קטלוג, חלופות, שרירים וקישורי הדגמה.
- `app.js`: מסכי כוח/אירובי, תיעוד, טיוטות, היסטוריה ותוספות.
- `insights.js`: סיכום פונקציונלי והתקדמות מתיעוד בפועל.
- `supabase/functions/workout-api/index.ts`: אימות, קריאת ההיסטוריה המלאה ושמירה עם מספר גרסה.
- `supabase/migrations/`: הוספת התוכנית תוך שימור הנתונים הישנים.
- `docs/demo-links-2026-11-06.json`: תיעוד אימות 38 ההדגמות. סרטוני Vimeo מוגבלים לאתר המקור ולכן נשמר קישור לעמוד ההדגמה, ולא קישור נגן עצמאי.

לחלופות ציוד יש מפתחות תיעוד נפרדים. תיעוד ישן ללא ציון הציוד מוצג כלא מוגדר ולא משמש השוואת עומס בין מכונות. מרחק נשיאה אינו מעורבב עם תיעוד קודם בשניות. הבחירות והתוספות נשמרות ב־`exercise_notes.__noga_ui_v3__`; מטא־נתונים מהגרסה הישנה נשמרים בעת עריכה. מפתחות הטיוטות הקיימים נשארו תואמים ומופרדים לפי משתמשת.

## בדיקות

```sh
node --test tests/program.test.cjs
node tests/browser.test.cjs
```

בדיקות הדפדפן דורשות Playwright; הנתיב לחבילות מתקבל מ־`CODEX_PRIMARY_RUNTIME_NODE_MODULES`, וניתן להעביר `CHROME_PATH` לבינארי Chromium מותקן. בדיקות השרת והדפדפן החי מקבלות נתיב לקובץ פרטי של שני חשבונות בדיקה זמניים. אין להריץ אותן על חשבון של מתאמנת. נתוני הבדיקה נמחקים לאחר האימות. אפשר להעביר `QA_BASE_URL` לבדיקת האתר שפורסם.

## פרטיות ותאימות

המאגר ציבורי: אין לשמור בו אימונים אמיתיים, מפתחות סודיים או קישורי גישה אישיים. השרת שומר hash של מפתח הגישה, ומאמת בעלות לפני כתיבה. האימות נעשה בשרת; טבלאות הנתונים אינן פתוחות לקריאה מהדפדפן.

עדכון השרת תואם גם לממשק הישן. שמירה חוזרת זהה אינה יוצרת כפילות. שינוי הערה אישית נכלל בחישוב תוכן האימון. בדיקת גרסה מקדימה מחזירה 409 על עריכה מיושנת לפני הקריאה הטרנזקציונית. נעילת הכתיבה הקיימת נשארת פעילה.
